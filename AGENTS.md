# Repository identity

This Demo Radar repository uses the personal GitHub account `roygrssmn`.
Verify the authenticated login before creating commits, branches, PRs, releases
or repository changes. Never fall back to a different connected account or
choose an account from an existing PR's author.

Use the personal author/committer identity and keep account checks enabled.
Preserve actual third-party and bot provenance. Do not change visibility,
publish, merge or deploy unless the user's task authorizes that action.
